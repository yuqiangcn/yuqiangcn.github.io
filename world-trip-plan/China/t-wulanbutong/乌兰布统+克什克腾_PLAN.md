## 国庆错峰总策略（行程全部围绕这6条设计）

1. **10.1 凌晨5:30出发**：出京峰值在8-12时（京承望和桥-来广营桥段6:00起承压），凌晨出发仅入口段有缓行风险，过怀柔即通畅；娃上车接着睡回笼觉
2. **10.1 只到多伦、不过夜乌兰布统**：完全避开景区入园最疯狂的国庆首日；多伦非热门目的地，房价涨幅有限
3. **10.2 走西门入园**：南门（塞罕坝方向）下午4点后大堵车；御道口方向西门车流少很多，再叠加12-14点入园次优时段，双保险
4. **景区内赶两头**：6:30前入园 / 12-14点入园 / 17点后出，避开8:30-9:30高峰（国庆实测此时段十几公里走1.5小时）
5. **10.7 早6:30返京**：返程最高峰在10.6-10.7的14-19时进京方向，15点前到家即避开
6. **全程高速免费**：D1凌晨上高速、D7午后下高速，均在免费时段内

## Day 1｜10.1（周四·国庆首日）北京 → 多伦

**驾驶段（凌晨避峰日）**

- 路线：京承高速G45 → 怀柔出口 → G111京加路（丰宁方向）→ 丰宁上G95张承高速（张家口方向）→ 大滩/多伦出口下 → G239 → 多伦县城

- \~400km，纯驾驶5-5.5h，含休息6-6.5h

- ⛽ 北京出发满油；多伦县城中石油/中石化齐全

**时间轴**

- 5:30 出发（娃睡醒直接抱上车，全程回笼觉；大人轮流驾驶；入口望和桥段如遇缓行不焦躁，过怀柔即通畅）

- 8:30-9:00 丰宁/大滩服务区早餐+休整（坝上旅游镇，可补零食）

- 12:30 抵多伦，县城午餐（坝上作息晚，迟到午餐正常）

- 14:30-15:30 **汇宗寺**（导航"汇宗寺"，1小时，殿宇清净游客少，门票小额）

- 15:40-16:20 **山西会馆**（40分钟，"草原码头"晋商会馆，古建密度超预期，门票小额）

- 16:30-17:00 超市大采购：面包、水果、零食——给D2-D4草原段备粮（乌兰布统乡内超市贵且选择少）

- 18:00 晚餐：铜锅涮或手把肉

- 19:30 回房早收工，早睡（后面连玩六天，今晚是储备）

**娃安排**：凌晨出发全程睡回笼觉；下午古建随意遛；海拔已上1300m，第一天不排体力项
**🛏 多伦县城（300-400元）**：县城中心（多伦大街/政务广场一带）连锁或本地酒店，确认暖气/地暖+独立卫浴

## Day 2｜10.2（周五）元上都 → 御道口 → 乌兰布统（西门入园）

**驾驶段**

- 路线：多伦 → 快速路 → 正蓝旗上都镇（42km，40分钟）→ 元上都遗址（19km）→ 返回北上 → 御道口镇 → 国家一号风景大道 → **乌兰布统西门** → 乌兰布统乡（红山军马场）

- 全天\~160km，3-3.5h（含游览）

- ⛽ 多伦出发前满油（多伦→乌兰布统之间加油站稀疏）

**门票（核心，务必看清）**

- **元上都遗址**：40元/人，娃免票；9:00-17:30（往年10月上旬后进入闭园期，出发前电话确认10月开放）

- **乌兰布统通票**：120元/人（携程/美团线上约118），自首次检票起**3日内无限次进出**（覆盖D2下午至D4全天）；6周岁或1.2米以下免票；**车辆免费进入、景区内路网全部自驾**；国庆分时限流，**提前3-5天在官方公众号/携程/美团预约**

- 御道口段为过路性质，沿主路直行不进太阳湖等收费点（联票80元仅含湖群，路过不游）

**时间轴**

- 8:30 出发

- 9:30-11:00 **元上都遗址**（世界文化遗产，金莲川草原上的元代都城残垣，1-1.5小时足够，大人拍照出片）

- 11:15 北上，娃上车午睡

- 12:30 御道口镇午餐

- 14:00-14:30 **乌兰布统西门购票入园**（御道口方向车流远少于南门，避开南门下午4点后大堵车）

- 15:00 抵乌兰布统乡（红山军马场），入住+简餐

- 15:30-17:30 **公主湖**（乡西约10km，15分钟车程）：湖边栈道+白桦倒影，下午顺光；娃湖边草坡撒欢

- 18:00 前后日落（10月初坝上日落约18:00），拍完收工

- 18:30 晚餐（铁锅炖/手把肉），20:00 回房

**🛏 乌兰布统乡/红山军马场（600-900元，第1晚/共3晚）**：必选地暖或水暖+独立卫浴+院里能停车；确认不是纯烧炕房

## Day 3｜10.3（周六）乌兰布统核心风光日（北线+南线）

**全天景区内自驾环线\~60km，不挪窝。今天是周六、景区人流最高日，赶早是唯一解**

**时间轴**

- 6:15 出发（赶在6:30前入园，比一日游大部队早2小时）

- 7:00-12:00 **北线**：影视基地（晨光侧逆光最出片）→ 百草敖包 → 将军泡子（芦苇+水面+远山，慢逛1小时）

- 12:00 回乡午餐，13:00-15:00 娃午睡（大人小憩/整理照片）

- 15:00-17:30 **南线**：北沟（丘陵+白桦林光影，随时停车）→ 五彩山（层林尽染，全程颜值巅峰）→ 东沟/夹皮沟方向看日落

- 18:00 日落，18:45 晚餐

- 备选：五彩山日出约6:05，轮流制——一人先去拍，8点回补觉（留人陪娃，不独留娃在车内/房内）

**驾驶要点（景区内）**

- 主路柏油/平整砂石，SUV无压力；**只走既有路，任何情况不碾压草地**（保护区，碾压草场违法）

- 北沟、五彩山部分路段为土路，**雨后24小时内只走主路**，泥泞土路宁可放弃

- 牛羊马群随时横穿：减速让行、不鸣笛

**🛏 乌兰布统，第2晚**

## Day 4｜10.4（周日）乌兰布统西线 + 草原体验日

**时间轴**

- 8:30 出发**西线**：盘龙峡谷（峡谷+溪流+桦林）→ 野鸭湖（湿地芦苇，娃数鸭子）

- 11:30 回乡午餐，12:30-14:30 娃午睡

- 15:00-17:00 **草原体验**：正规马场骑马（教练牵马、大人带娃共骑，50-100元）+ 喂小羊 + 蒙古包里喝奶茶

- 17:30 收拾行李（明晨早退房）、备明早干粮

- 18:00 就近日落机位补拍（前两天没拍够的点）

- 18:30 晚餐：烤羊腿点半份尝鲜

**今天刻意排松**——D3拍了整天，让大人的手和娃的腿都歇一歇；明天起连续三个驾驶日。

**🛏 乌兰布统，第3晚**

## Day 5｜10.5（周一）蛤蟆坝 → 桦木沟 → 经棚 → 热水塘

**驾驶段（景观路+换基地日）**

- 路线：乌兰布统乡 → 经乌线西行 → **蛤蟆坝**（35km）→ 桦木沟林场 → 经棚镇 → G303东北行30km → 热水塘镇

- \~150km，3-3.5h（含停留）

- ⛽ **经棚镇满油**（中石油/中石化齐全，后半程最重要补给点）

**时间轴**

- 5:30 出发拍**蛤蟆坝日出+晨雾**（轮流制）；起不来就7:00出发，晨雾尾声到9点前仍可观，娃多睡1小时

- 6:30-10:00 **蛤蟆坝**：乌兰布统西侧秋色王牌，摄影圈私藏，人比核心区少一半、秋色不输（门票约30元/人；S304主干道两侧免费）；坝上秋林+沟谷光影

- 10:00-12:00 桦木沟一路白桦夹道，随停随拍

- 12:30-13:30 经棚镇午餐（对夹、锅包肉、牛肉干）+满油

- 14:30 抵**热水塘镇**（克什克腾旗热水开发区，经棚东北30km，303国道旁），入住温泉酒店

- 15:00-17:30 **泡汤**：连玩四天全家回血，娃也泡（注意水温、时间短一些）

- 18:00 镇上晚餐，20:00 回房——疗养镇，国庆比乌兰布统安静得多、便宜得多

**🛏 热水塘温泉酒店（500-700元，含温泉，第1晚/共2晚）**

## Day 6｜10.6（周二）热阿线+达达线大环日（全程高光）

**\~330km，纯驾驶约6h；两条均为柏油双车道，轿车可走，不涉水、不走牧道；逐点详表见下章③**

**时间轴**

- 7:30 出发（赶早：国庆黄岗梁段会堵车；娃睡醒吃饱再走）

- 8:00-10:00 热阿线翻**黄岗梁**（大兴安岭最高峰，白桦+落叶松彩林，观景台停1-2次）

- 10:00-11:30 **阿斯哈图石林**门区打卡（默认不进园；进园120-160元含摆渡车约2小时——今天重点是路和湖，石林以后可专程）

- 11:30-12:30 达达线南下，**白音敖包**沙地云杉路边远观（世界唯一沙地云杉林）

- 12:30-13:30 达来诺日镇简餐补给（小镇餐馆，别期待太高）

- 13:45-15:15 **达里湖北岸观鸟**（90元/人，娃免票）：10月正值大天鹅南迁停歇，北岸观鸟长廊是最佳观测点，全程压轴

- 15:30-17:30 G303东行，经棚（如需补油）→ 热水塘（娃车上睡午觉）

- 18:00 到镇再泡一次汤收尾，**今晚早睡**（明晨6:30出发返京；若选变体B见下方决策点）

**⚠️ 本日特别提醒**

- **信号**：黄岗梁段+贡格尔段信号弱甚至无服务——出发前下载"赤峰/克什克腾旗"离线地图（高德/百度均支持），当天所有POI提前收藏

- **牛羊横穿**：贡格尔草原牛羊成群过路是常态，减速让行、不鸣笛

- **湖岸风大**：观鸟穿冲锋衣；若风力7级以上天鹅缩在远处，就近湖岸看看即走

- **预期管理**：10月初草原远看偏绿，"金色"主要靠林木灌木撑

- **轻量版备选**（天气/体力不佳）：只走热阿线到黄岗梁往返（~120km），下午回温泉躺平；达达线+观鸟留给下次

**🔄 现场决策点：东进赤峰（变体B）——看完天鹅 15:00 在湖边停车场定**

赤峰本就在 D7 返京线上，B 版本质是把次日清晨的 ~250km 提前到 D6 傍晚走掉（总里程约 -50km）：

| | A · 回热水塘（默认） | B · 东进赤峰 |
| - | --- | --- |
| D6 剩余 | 120km / 1.5h，17:30 到 | 340km / 4.5h，~20:00 到 |
| 今晚 | 泡汤回血 + 早睡 | 大板 17:30 快晚餐（对夹），到店即睡 |
| D7 | 6:30 出发，670km / 8h | 8:00 出发，410km / 5h |
| 到家 | ~15:00 | ~14:30 |
| 适合 | 全天玩累、想要温泉回血 | 状态好、最后一天睡到自然醒 |

选 B 的操作：黄岗梁观景台只停 1 次、石林门区不停、湖边 **15:00 撤离**；经棚过路补油；大板 17:30 快餐；20:00 到赤峰（住高速口/桥北一带）。**两边房都订"可免费取消"**（热水塘第 2 晚 + 赤峰 10.6 一晚），15:00 湖边二选一，18:00 前退掉另一间。若 D7 预报承德-北京段午后有雨或事故高发，选 B 更稳；预算基本持平（赤峰房约比温泉房省 100-200 元）。

**🛏 热水塘，第2晚（默认A；变体B：赤峰市区，高速口/桥北一带）**

## Day 7｜10.7（周三）热水塘 → 北京（早返避峰日）

**驾驶段**

- 路线：热水塘 → 经棚 → G16丹锡高速（赤峰方向）→ 赤峰 → G45大广高速 → 承德 → G45京承高速 → 北京

- \~670km，纯驾驶约8h；以导航实时推荐为准（备选：经棚→G303→桑根达来→G95/G6张家口方向回京，里程相近）

- ⛽ 热水塘出发满油

**时间轴**

- 6:00 早餐，6:30 出发（赶早不赶晚：返程最高峰在14-19时进京方向，15点前到家即避开）

- 9:30-10:00 赤峰服务区休息

- 11:30-12:30 服务区或赤峰出口简餐快走

- 14:00-14:30 承德一带服务区休息（娃午睡安排在午后任一车程）

- 14:30-15:00 到家，晚上在家吃口热的，早睡（明天上班）

- 若导航显示京承进京段缓行：改走G45→G95/G6张家口方向绕行
- **变体B（D6东进赤峰）**：出发顺延至 8:00-8:30，赤峰 → G45 → 承德 → 京承 ~410km/5h，14:30 前到家——返程晚高峰彻底无虞，还能多睡 1.5 小时

## 天气决策与安全

**天气决策点（9.24，出发前一周核三项）**

- 乌兰布统10天内有无强寒潮/暴雪；黄叶实况（搜"乌兰布统 实况"，每年浮动可达一周）；达里湖一带风力

- **降级预案**：预报寒潮大雪 → 放弃本线，启用同目录 `../t-weixian/蔚县+涞源` 低海拔5日线

- **微调预案**：仅D6有雨 → 达达线改轻量版；仅D3-D4有雨 → 土路点位（北沟/五彩山）顺延半天，先走铺装点位（公主湖/将军泡子）

**安全6条**

1. **不碾压草场、不进牧道**：只走既有车辙和正式道路，碾压草场违法且近年被重点整治
2. **牛羊横穿**：提前减速、停车让行、**不鸣笛**（惊了牲畜牧民会索赔）
3. **信号盲区**：热阿线黄岗梁段、达达线贡格尔段信号弱——车上不留人、不远离车、不走夜路
4. **夜温0℃以下**：早晚给娃戴帽子（头颈部散热占大头）；酒店选地暖不是矫情
5. **高反无虞**：全程海拔1200-1700m，普通人无感，但第一天别安排剧烈活动
6. **日出拍摄轮流制**：绝不单独把娃留在车里或房里
