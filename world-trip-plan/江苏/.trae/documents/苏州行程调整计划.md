# 计划：苏州 6 晚 → 5 晚，挪 1 晚给上海（最终版）

## 摘要（规划师结论 + 决策依据）

**推荐：苏州 5 晚（9.30-10.4）+ 上海 2 晚（10.5-10.6），10.6 为城市漫游日（用户已确认）。**

判断过程——四个候选里为什么是"挪给上海"：

| 候选 | 判断 | 关键理由 |
|---|---|---|
| **A 挪1晚给上海** ✅ | **采纳** | ① 用户已确认想要"上海一整个白天"，维持6晚与此矛盾；② 现方案10.6是全行程最过载的一天（赶车+豫园+自博+外滩轮渡塞一天，次日6点起床赶7点G4），拆成两天是唯一解法；③ 苏州5整天内容实际到10.5中午就消化完，10.5下午现安排是填充项（北寺塔/观前街/打包） |
| B 维持6晚 | 否 | 唯一优势是少换一次酒店，但代价是保住一个已知的最弱日；10.5下午的空档无论填同里还是华谊电影世界，都制造新的赶路或排队 |
| C 苏州5晚+同里1晚 | 否 | 水乡过夜体验好，但同里民宿无电梯、品质参差（与"观前街连锁家庭房"的带娃订房策略冲突）；10.6从同里赶回上海又重演"半天塞三景"；平江路手摇船+山塘街+扬州古运河已覆盖运河体验，边际价值低 |
| D 砍苏州到4晚 | 否 | 必须牺牲西山（太湖补位）或留园/艺圃日，破坏"国庆峰值稀释"结构，动作过大 |
